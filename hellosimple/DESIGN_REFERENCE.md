# HelloSimple design reference

HelloSimple should feel calm, clean, capable, and professional.

## Reference blend
- Scribe: procedural clarity
- Guidde: contextual teaching
- Whiteout Survival: visible progression and reward logic only
- MSH: human + AI work, occupational growth, contribution, and durable impact evidence

## Visual rules
- No game animation, fantasy scenes, noisy effects, confetti, or decorative motion.
- Progress should be visible but subordinate to the work.
- Use generous whitespace and clear hierarchy.
- One primary action per card where practical.
- Human-needed actions must be visually distinct from AI-active work.
- Reward cards should explain what was earned and why.
- Skills should show evidence state, not just a decorative score.
- Daily schedule should read like a calm operating brief, not a dense project manager.

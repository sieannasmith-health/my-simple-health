# HelloSimple employee interface

HelloSimple is the signed-in MSH workforce hub. This MVP is a functional front-end prototype for the Employee Journey & Impact System.

## Product references

- Scribe: procedural, step-by-step work guidance.
- Guidde: contextual training and walkthroughs.
- Whiteout Survival: progression logic only (XP, levels, milestones, rewards), with no game animation or fantasy presentation.
- MSH: real work, Hello Workers, human judgment, skills, contribution, impact, and career evidence.

## MVP behavior

- Daily Today view showing priorities, schedule, human-needed actions, and AI-worker activity.
- Missions tied to company objectives and skill development.
- XP, levels, milestone rewards, and responsibility progression that never automatically grants sensitive authority.
- Impact Portfolio records meaningful results and keeps human contribution distinct from AI execution.
- Separate Siea and Brandon pilot profiles.
- Local persistence for prototype state and profile photo.

## Follow-up integration

Authentication, durable backend persistence, live calendar/objective ingestion, real Hello Worker runtime status, and production permissions are separate integration tasks. The interface must continue to work as a coherent shell while those sources are connected.

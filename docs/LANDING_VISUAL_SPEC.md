# My Simple Health landing visual specification

The public landing page should preserve the approved MSH visual language rather than flattening mockups into generic content sections.

## Required visual language

- Editorial, Local Project-inspired composition with strong negative space around meaningful visual objects.
- Large-scale imagery used as part of the composition, not as decorative wallpaper.
- Forest, cream, warm white, sage, and charcoal remain the primary palette.
- Serif-led hierarchy with restrained supporting sans-serif typography.
- Product cards and kinetic information should visibly demonstrate how MSH organizes health information.
- Motion must reveal relationships or interpretation. It should not exist only for decoration.
- Landscape should show dimensions forming a coherent whole.
- Calendar, Discovery, Practice, and Journey examples should visually demonstrate time, relationship, experimentation, and continuity.
- Actual MSH product imagery should appear in the landing story.
- Restraint means fewer competing systems, not empty pages.

## Implementation rule

An approved mockup is a visual specification. A landing implementation is not complete until the running page has been visually compared against the approved composition and corrected for major differences in imagery, scale, spacing, cards, hierarchy, and motion.

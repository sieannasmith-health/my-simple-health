Troubleshooting

Start here when something is not loading, saving, displaying, or responding as expected.

A page looks outdated

Refresh the page first. If a recent update has just been released, your browser may briefly have an older asset cached while the current deployment becomes available.

AI is not responding

Retry the request once. If the service is unavailable, MSH should show a readable error rather than raw HTML or technical response text. If the problem continues, report the page and what you were trying to do.

Information is not saving

Keep the page open if possible and retry the action. Some current MSH experiences use browser-local persistence while account-backed storage is still being expanded.

The layout looks broken

Try refreshing at your normal browser zoom. If controls overlap, raw navigation appears, or unstyled HTML is visible, please report the page, device, and browser so the rendering problem can be reproduced.

Still stuck?

Send the page name, what you expected to happen, what actually happened, and a screenshot if useful.
